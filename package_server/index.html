📦 Repository einrichten

Folgen Sie diesen Schritten, um das Edulution-Repository auf Ihrem System zu installieren:

1 GPG-Schlüssel hinzufügen

Fügen Sie den öffentlichen Schlüssel des Repositories hinzu:

curl -fsSL https://package.edulution.io/pub.gpg | sudo gpg --dearmor -o /usr/share/keyrings/edulution.gpg
2 Repository zur Quellenliste hinzufügen

Fügen Sie das Repository zu Ihrer APT-Konfiguration hinzu. Der Ubuntu-Codename wird dabei automatisch erkannt, sodass der Befehl auf jeder unterstützten Ubuntu-Version funktioniert:

echo "deb [signed-by=/usr/share/keyrings/edulution.gpg] https://package.edulution.io/ $(. /etc/os-release && echo "$VERSION_CODENAME") main" | sudo tee /etc/apt/sources.list.d/edulution.list
3 Paketliste aktualisieren

Aktualisieren Sie die Paketquellen:

sudo apt update
Unterstützte Ubuntu-Versionen: Ubuntu 24.04 LTS (noble) und Ubuntu 26.04 LTS (resolute). Der Befehl in Schritt 2 erkennt die installierte Version automatisch über /etc/os-release.
Einmalige Meldung nach der Umbenennung: Die Distribution hieß intern früher nobel und heißt jetzt korrekt noble. Auf Systemen, die das Repository vorher schon eingebunden hatten, bricht apt update deshalb einmalig mit „… changed its 'Codename' value from 'nobel' to 'noble'“ ab. Einmal bestätigen genügt:
sudo apt update --allow-releaseinfo-change
Danach funktioniert apt update wieder wie gewohnt. Neu eingerichtete Systeme sind nicht betroffen.
